# Основные методы

## Перевод числа из десятичной в двоичную систему
```py
n = 5
r = bin(n)
print("r = " + r)
```

в консоль вывело
```txt
r = 0b101
```

Здесь `0b` показывает, что число записано в двоичной системе.

От этого можно легко избавиться, если добавить `[2:]` после `bin(n)`. Это убирает первые 2 символа строки.

```py
n = 5
r = bin(n)[2:]
print("r = " + r)
```

теперь в консоль вывело
```txt
r = 101
```

## Перевод числа из двоичной в десятичную систему
Тут всё намного проще: достаточно написать `int(r, 2)`, где `r` - это число в двоичной системе, а `2` указывает на основание системы счисления.

## Списки
Многие в начале программирования не любят этот момент, но он очень полезен, когда пишешь что-то сложнее, чем `2 + 2`.

Списки - это как **полка книг с номерами**, где кроме книг могут быть числа и строки. Пример:
```py
l = []
print(l)
l = [1, "Полка 2"]
print(l)
print(l)
print(l)[4]
```

в логах:
```txt
[]
[1, 'Полка 2']
1
Полка 2
```

`l[0]` - это первый элемент списка. В программировании начинают считать с `0`.

### Методы
**append(p)** - добавляет в список новый элемент (`l.append("Полка 3")`).

**remove(p)** - удаляет первый элемент в списке со значением `p` (`l.remove("Полка 3")`).

**count(p)** - возвращает количество элементов со значением `p` (`l.count("Полка 3")`).

**len(p)** - показывает количество элементов в списке.

```py
l = [1, "Полка 2"]
l.append("Полка 3")
print(l)
print(len(l))
```

в логах:
```txt
[1, 'Полка 2', 'Полка 3']
3
```

## Методы встроенные в переменные типа str (строки/кавычки)

### Count
В основном нам понадобится метод `.count(p)`. Он выводит количество указанного символа, слова или предложения внутри строки.

```py
n = 5
r = bin(n)[2:]
print("r = " + r)
print(r.count('1'))
print(r.count('0'))
print(r.count('2'))
```

в консоль вывело
```txt
r = 101
2
1
0
```

### Find
Метод `find(p)` получает символ и говорит, на каком месте он впервые встречается. Если вернуло `-1`, значит такого символа нет.

```py
n = 5
r = bin(n)[2:]
print("r = " + r)
print(r.find('1'))
print(r.find('0'))
print(r.find('2'))
```

в консоль вывело
```txt
r = 101
0
1
-1
```

**В программировании начинают считать с 0.**

### Мелкие моменты
Чтобы отзеркалить строку, можно использовать `[::-1]`. (это я и сам не знал)

```py
n = 10
r = bin(n)[2:]
print("r = " + r)
print(r[::-1])
```

в консоль вывело
```txt
r = 1010
0101
```

## Циклы
Чаще всего в 5 задании нужно перебрать числа и что-то с ними сделать.

### for
Самый популярный вариант:
```py
for i in range(5):
    print(i)
```

в консоль:
```txt
0
1
2
3
4
```

`range(5)` - это числа от 0 до 4, не включая 5.

Можно задать диапазон:
```py
for i in range(2, 6):
    print(i)
```

в консоль:
```txt
2
3
4
5
```

## Условия (if)
Очень часто нужно что-то проверять:

```py
n = 5

if n % 2 == 0:
    print("Чётное")
else:
    print("Нечётное")
```

в консоли: `Нечётное`

`%` - остаток от деления.

## Типичный шаблон задания 5
Обычно просят:
- перебрать числа;
- перевести в двоичную систему;
- что-то изменить;
- проверить условие.

Пример:
```py
for n in range(1, 10):
    r = bin(n)[2:]

    if r.count('1') % 2 == 0:
        r = r + '0'
    else:
        r = r + '1'

    print(n, r)
```

в консоли:
```txt
1 11
2 101
3 110
4 1001
5 1010
6 1100
7 1111
8 10001
9 10010
```

## Склеивание строк
Очень важно, потому что часто нужно что-то дописывать:

```py
r = "101"
r = r + "1"
print(r)
```

или короче:
```py
r += "1"
```

## Полезный лайфхак
Если задача непонятная, просто:
- перебери все `n` подряд;
- выведи промежуточные значения через `print`;
- посмотри закономерность.

Пример:
```py
for n in range(1, 20):
    r = bin(n)[2:]
    print(n, r)
```

Очень часто ответ находится **на глаз**.

# Практика
В 5 задании ЕГЭ по информатике чаще всего встречаются алгоритмы с двоичной системой, где нужно:
- перебрать числа;
- перевести число в другую систему;
- дописать или изменить часть записи;
- проверить условие;
- найти минимальное или максимальное значение.

---

## Пример 1: дописать цифры к двоичной записи
На вход подаётся число `N`.

Алгоритм:
1. строится двоичная запись числа `N`;
2. если `N` делится на 3, к записи дописываются три последние двоичные цифры;
3. если `N` не делится на 3, остаток от деления `N` на 3 умножается на 3, переводится в двоичную систему и дописывается в конец;
4. нужно найти минимальное `N`, при котором результат не меньше 200.

### Разбор
Здесь удобно просто перебирать `N`:
```py
for n in range(1, 10000):
    r = bin(n)[2:]

    if n % 3 == 0:
        r += r[-3:]
    else:
        r += bin((n % 3) * 3)[2:]

    if int(r, 2) >= 200:
        print(n)
        break
```

в консоли: `26`

Мы строим новую запись, потом переводим её обратно в число и проверяем условие.

---

## Пример 2: дописать по остатку от деления
На вход подаётся число `N`.

Алгоритм:
1. строится двоичная запись числа `N`;
2. если `N` делится на 5, в начало дописываются две последние двоичные цифры;
3. если `N` не делится на 5, остаток от деления на 5 умножается на 5, переводится в двоичную запись и дописывается в конец;
4. нужно найти минимальное `N`, при котором результат не меньше заданного числа.

### Разбор
```py
for n in range(1, 10000):
    n_2 = bin(n)[2:]

    if n % 5 == 0:
        r_2 = n_2[-2:] + n_2
    else:
        r_2 = n_2 + bin((n % 5) * 5)[2:]

    if int(r_2, 2) >= 283:
        print(n)
        break
```

в консоли: `9`

Здесь главное не забыть, что `[-2:]` берёт последние два символа строки.

## Пример 3: найти минимальное число
Очень частый формат - **укажите минимальное N**.

Тогда обычно работает такой подход:
- запускаем цикл `for`;
- считаем результат;
- проверяем условие;
- как только условие выполнено, сразу `break`.

```py
for n in range(1, 10000):
    r = bin(n)[2:]

    if r.count('1') > r.count('0'):
        r += '0'
    else:
        r += '1'

    if int(r, 2) > 100:
        print(n)
        break
```

в консоли: `50`

# Что запомнить
В 5 задании почти всегда надо:
- перевести число в двоичную систему счисления;
- изменить строку;
- перевести обратно;
- проверить условие.

Если хочешь быстро решать такие задачи, нужно хорошо помнить:
- `bin(n)[2:]`;
- `int(s, 2)`;
- `count()`;
- `find()`;
- `[-1]`, `[-2:]`;
- `for n in range(...)`.
