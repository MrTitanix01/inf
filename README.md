# Основы
Для выполнения заданий ЕГЭ по информатике обычно используют Python, потому что в нём легко начать писать программы и быстро проверять идеи.

В Python не нужно заранее указывать тип переменной. Например:
в Python:
```py
a = 5
b = 5.5
c = "Test string"
```
а в Java:
```java
package ru.blatfan.blatapi;

public class Main {
    public int a = 5;

    public float b = 5.5f;
    // или
    public double b2 = 5.5d;

    public String c = "Test string";
}
```

Ещё в Python не нужно ставить `;` в конце каждой строки, как во многих других языках программирования.

## **!!! В программировании нумерация начинается с 0 !!!**
