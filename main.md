# Основы
Для выполнения заданий из ЕГЭ по информатике используют Python из-за лёгкого старта. 

В Python не требуется назначать тип переменной, пример:
в Python:
```py
a = 5
b = 5.5
c = "Test string"
```
а в Java:
```java
package ru.blatfan.blatapi;

public class Main {
    public int a = 5;

    public float b = 5.5f;
    // или
    public double b2 = 5.5d;

    public String c = "Test string";
}
```
Явно больше 2-х строк

Так же в Python не требуется ставить ';' в конце каждой строчки, как во многих других языках программирования.

## **!!! В программировании начинают считать с 0 !!!**
